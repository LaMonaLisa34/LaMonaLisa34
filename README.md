# Mona van Willigen

## Conceptrice développeuse d’applications

Je conçois des applications de bout en bout : analyse du besoin, architecture, expérience utilisateur, développement, tests et déploiement.

Mon parcours en architecture, en entrepreneuriat et dans le numérique m’a donné une approche transversale des projets. Je travaille actuellement sur des applications liées aux exigences non fonctionnelles : API Python, automatisation des tests, planification de traitements, interface React et CI/CD.

**Développement :** Python · JavaScript · React · Symfony · Django

## Projets

### Alinéa

Application de production de contenus structurés assistée par IA.

Génération à partir de sources, de consignes et de modèles configurables, avec validation humaine. Projet de fin d’études en développement, conservé dans un dépôt privé.

### Chevaux du Monde

Plateforme consacrée aux races équines : développement Symfony et Twig, base de données relationnelle, gestion éditoriale, versions française et anglaise, SEO et optimisation des performances.

[chevauxdumonde.com](https://chevauxdumonde.com)

### E-commerce de matériel informatique reconditionné

Application Symfony comprenant la gestion des produits, du panier, des commandes, des paiements PayPal, des remboursements, des factures PDF et de l’administration.

[Voir le dépôt public](https://github.com/LaMonaLisa34/E-commerce-Materiel-Informatique-Reconditionne)

### Vorpal Hexapode

Fabrication et configuration d’un robot hexapode open source : impression 3D, assemblage mécanique, électronique et commande Bluetooth.
